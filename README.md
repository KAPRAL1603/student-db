# 🎓 Student Management Console App (Java + JDBC + H2)

Учебный проект для демонстрации работы с JDBC, базами данных и архитектурой Java-приложения.

## 🚀 Возможности

- ➕ Добавление студента  
- 🔍 Поиск студента по паспорту (серия + номер)  
- ❌ Удаление студента  
- 💾 Сохранение данных в базе (H2)  
- 🛡️ Защита от дубликатов (уникальность паспорта)  

---

## 🛠️ Технологии

- Java (Core)  
- JDBC  
- H2 Database (embedded)  
- Gradle  

---

## 🏗️ Архитектура

- View — консольный интерфейс  
- Controller — обработка запросов  
- Service — бизнес-логика  
- Database — работа с БД  
- DTO / Model — структура данных
